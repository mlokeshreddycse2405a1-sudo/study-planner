# Study Planner
Smart Study Planner

## Description
Study Planner is a basic frontend web application designed to help students organize study tasks, manage subjects, and monitor academic progress in a simple and motivating dashboard.

## Features
- Task management
- Subject organization
- Priority management
- Task completion
- Task filtering
- Progress tracking
- Local storage
- Responsive design

## Technologies
- HTML5
- CSS3
- JavaScript
- Git
- GitHub

## Project Structure
- `index.html` — landing page for the application.
- `dashboard.html` — main study dashboard where tasks are managed.
- `style.css` — global styling and responsive layout.
- `script.js` — task logic, filtering, progress updates, and local storage handling.
- `README.md` — project overview and instructions.

## How to Run
Open `index.html` in a browser to use the Study Planner landing page, or open the project in VS Code and launch it with Live Server for a smoother development experience.
